# Trade Learn 📈

**1v1 Real-Time Stock Trading Battles** — Challenge a friend to a 10-minute paper-trading duel on Indian markets.

## Features

- 🔥 **Live Candlestick Charts** — Tick-by-tick simulated NSE candlesticks
- 🏟️ **Private Rooms** — Create a room, share the code, start trading
- 🤖 **MarketBot** — Practice against an AI opponent
- 🏆 **Global Leaderboard** — XP, wins, and net P&L rankings
- 📊 **Match Review** — Full trade history, holdings, and P&L breakdown

## How to Play

1. **Sign up** and create an account
2. **Create a Match** to get a 6-letter room code
3. **Share the room code** with your friend
4. Enter the code in **Join Match** on the dashboard
5. Host clicks **START DUEL** — 10 minutes on the clock!

## Tech Stack

- React 19 + TanStack Start (full-stack)
- Tailwind CSS v4
- Zustand (with localStorage persistence)
- Framer Motion
- TradingView Lightweight Charts

## Development

```bash
npm install
npm run dev
```

Open [http://localhost:8080](http://localhost:8080)

## Room Sharing Note

Rooms are stored in **localStorage** — this means:
- Room codes work when joined on the **same device/browser**
- Share the **room code** directly with your friend to join
